# 安全测试报告（T11.3 / V11-3）

## 范围与方法

- 用例文件：`backend/tests/test_security_i11.py`（15 个用例，全部通过）。
- 执行：`cd backend && uv run pytest tests/test_security_i11.py -q`。
- 覆盖开发文档 9.5 五类安全项：越权、认证、注入、业务安全、信息泄漏。

## 结果

| 类别 | 用例 | 结果 |
| --- | --- | --- |
| 水平越权 | 他人订单 / 地址 / 客服会话按 `public_id` 访问 | 均 404，不泄露资源存在性 |
| 垂直越权 | 会员访问后台列表、审核、SKU 库存调整 | 均 403 |
| 未认证 | 购物车、订单、地址等受保护接口 | 均 401 |
| Token 安全 | 篡改签名、过期 Token | 均 401 |
| 注入 | 搜索参数 SQL 注入、`ordering` 注入 | 参数被白名单校验，返回安全 JSON |
| XSS | 商品搜索关键词回显 | JSON 转义，不产生可执行 HTML |
| 上传伪装 | 评价图片改扩展名 / 超大文件 | 400 拒绝，类型与大小校验生效 |
| 信息泄漏 | 错误响应结构、内部标识 | 仅返回 `code/message/request_id/timestamp`，无堆栈与自增 ID |
| 业务安全 | 重复下单缺幂等键 | 400/422，明确业务码 |

## 结论

- 高危漏洞 0，越权 0，敏感信息泄漏 0，V11-3 通过。
- 已修复问题：E2E 过程中发现客服会话关闭后用户端状态不同步（前端轮询缺陷），已在 `SupportView.vue` 修复。
- 说明：DRF 未认证统一 401，越权资源统一 404；后台按 `admin/operator/support` 用户组判定权限。
