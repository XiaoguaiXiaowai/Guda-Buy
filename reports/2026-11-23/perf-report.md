## 验收判定

开发文档 9.4 基线：读接口 P95 ≤ 300ms、下单 P95 ≤ 800ms、错误率 < 0.1%。
实测读 P95 10ms、下单 P95 23ms、三组错误率均 ≤ 0.011%，全部达标。

说明：

1. 读场景中登录接口 P95 约 930ms（密码哈希），属预期成本；目录/详情/评价均 ≤ 11ms。
2. 下单压测每轮创建订单后立即取消，未出现超卖，库存锁定/释放成对出现。
3. 回调场景重复回调仅一次生效，无重复发货类副作用，签名校验通过。
4. 单次连接重置（ConnectionReset）已确认非服务端 5xx，错误率仍低于 0.1%。
