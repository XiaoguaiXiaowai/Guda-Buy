## 5. 上线前置条件

1. 生产 exporter 与 Alertmanager 接入，完成一次告警触达演练（对应 I11-1）。
2. 预发环境执行 `publish.sh` 与 `rollback.sh` 全流程，确认 rsync 与 systemd 重启正常（对应 I11-2）。
3. 生产 `.env` 按 `deploy/env.production.example` 配齐，确认 `DEBUG=False`、域名与密钥正确。
4. 发布前执行数据库备份并 `gzip -t` 校验。
5. 发布后确认 `/healthz/` 200 与 `smoke.sh` 5 项通过，再逐步放量。

## 6. 后续迭代建议

- 将 Playwright E2E 接入 CI，作为合入门禁。
- 接入 django-prometheus 或在 Nginx 层补齐接口级 P95 指标，完善告警。
- 每月执行一次备份恢复演练，保留核对 SQL 输出。
- 登录性能优化与慢查询巡检纳入日常运维。
