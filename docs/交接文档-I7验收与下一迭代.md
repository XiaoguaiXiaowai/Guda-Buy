## 4. 关键实现约定（I8 及以后沿用）

1. 金额唯一口径为 `apps/orders/pricing.py`：商品小计 → 券抵扣 → 运费 → 应付；任何新营销工具必须接入该函数，不得另写算法。
2. 运费门槛按**抵扣后的商品金额**判断（`ORDER_FREE_SHIPPING_THRESHOLD` 默认 99，`ORDER_SHIPPING_AMOUNT` 默认 10）；免邮券只把运费置 0，不改商品金额。
3. 券抵扣规则：`FIXED` 取 `min(value, eligible_amount)`；`DISCOUNT` 为 `eligible_amount × (1 - value)` 四舍五入两位；抵扣后商品金额最低 0.01。
4. `eligible_amount` 只统计命中适用范围（全场/分类含父分类/指定商品）的商品，不可用券必须返回原因。
5. 券状态机单向：`UNUSED → LOCKED`（下单）`→ USED`（支付成功）；取消/超时只处理 `LOCKED`，已过期退为 `EXPIRED`；过期任务只处理 `UNUSED`。
6. 订单幂等指纹包含 `user_coupon_public_id`；同幂等键不同券参数返回 409 `ORDER_IDEMPOTENT_REPLAY`。
7. 下单事务内先按订单商品二次校验并锁券，锁券失败整单回滚；Order 与 UserCoupon 双向绑定，取消后保留历史快照。
8. 支付成功在 `_apply_success` 事务内调 `mark_used_for_order`，支付金额只认 `order.payable_amount`。
